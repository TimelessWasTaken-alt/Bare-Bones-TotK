# Bare Bones TOTK — GitHub Pages

A responsive static website for the Bare Bones TOTK challenge rulebook. Includes interactive Late-Start checklist, Master Sword tracker, Wanderer regional tracker, effect-food tracker, survival run log, and image checklist.

## Publish on GitHub Pages
1. Create a GitHub repository (for example `bare-bones-totk`).
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. After publishing, visit `https://YOUR-USERNAME.github.io/bare-bones-totk/`.

## Customize
Edit `index.html` to update rules, wording, or colors. To add your own screenshots, upload them to an `assets/` folder and add image tags using their paths. Reuse your own supplied screenshot for the “No Restrictions” logo; this starter site does not recreate or bundle it.

The site is static: trackers are browser-side only and do not sync or permanently save progress. Use the Copy buttons to save progress elsewhere.
